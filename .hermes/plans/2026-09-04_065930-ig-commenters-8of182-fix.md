> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** `ig_post_commenters` jobs return only the first GraphQL page (~8 users) instead of all unique commenters (≥70% target) — fix pagination termination, media-id resolution, crash-recovery, and comment-text extraction.

**Architecture:** `fetchCommentsViaApi(shortcode)` in `ig-post-users.ts` paginates doc_id `9361150124142511` (`PolarisPostCommentsByShortcodeQuery`). ## Root causes (4)

1. **P0 — Single-shot network call has no retry.** In `fetchCommentsViaApi`, `this.page.evaluate(fn).catch(() => ({error:true,status:0}))` swallows transient network deaths as a permanent break → mid-pagination deaths truncate the harvest silently.
2. **P0 — First-page crash stops everything.** Page-1 GraphQL failure (`!result.comments?.length` → break) skips the rest of extract entirely — no DOM fallback, no stop_reason. The likers path solved this exact shape with `fetchLikersViaMediaEndpoint` fallback.
3. **P1 — `knownMediaPk` is derived from the shortcode but the media pk and comment pk differ.** `data.comment_id` is `"<comment_pk>_<media_pk>"`; the trailing segment is the true media id (og meta probe confirms `3978134670572337305`). The current `deriveMediaPk` value is wrong for this purpose → `bodyFilter` scoping and any pk-based logic misfire. Evidence: current job stored zero `comment_id`s.
4. **P2 — Probes will throw `ReferenceError: __name is not defined`.** `page.evaluate(async ({shortcode, after}) => {...})` (function form) is esbuild-transformed by tsx; page context lacks `__name`. Works only because local dev uses `tsx watch` that today doesn't inject it; probes and hardened builds break. (Project convention: template-string bodies.)

```ts
/** Media pk from a comment_id ("_<media>" suffix) or bare numeric pk. */
export function parseCommentMediaPk(commentId: string): string | null {
  const m = commentId.trim().match(/^(\d+)(?:_(\d+))?$/);
  if (!m) return null;
  return m[2] ?? m[1];
}

/** True when a comments page result is transient-failed and worth retrying. */
export function shouldRetryCommentsPage(status: number, usersLen: number, attempt: number): boolean {
  if (usersLen > 0) return false;          // success — never retry
  if (attempt > 3) return false;           // exhausted
  return status === 0 || status === 429 || status >= 500;  // network death / rate limit / server error
}

/** Resolve the comments connection from xdt, trying the 3 known edge keys in order. */
export function pickCommentsConn(xdt: Record<string, unknown> | undefined | null): {
  edges: Array<Record<string, unknown>>; pageInfo: Record<string, unknown> | null; count: number | null;
} {
  if (!xdt) return { edges: [], pageInfo: null, count: null };
  const conn = (xdt.edge_media_to_comment_thread_or_show_more_edge_or_toplined_comments
    ?? xdt.edge_media_to_parent_comment ?? xdt.edge_media_to_comment) as Record<string, unknown> | undefined;
  return {
    edges: (conn?.edges as Array<Record<string, unknown>> | undefined) ?? [],
    pageInfo: (conn?.page_info as Record<string, unknown> | undefined) ?? null,
    count: (conn?.count as number | null) ?? null,
  };
}
```

### Task 3: Rewrite `fetchCommentsViaApi` loop (root causes 1 + 2)

**Objective:** Retry transient failures on EVERY page; never break the whole job on a first-page crash; keep pacing; respect maxResults; stop on `source_exhausted` only at true end.

**Files:**
- Modify: `extraction-service/src/extractors/ig-post-users.ts` (`fetchCommentsViaApi`, ~lines 555-653)
- Modify: `extraction-service/src/extractors/ig-post-users.ts` (`extract()` step 4a — record `stop_reason` when the API path yields 0)

**Implementation sketch (exact code for the loop):**

```ts
const MAX_PAGES = 200;
const MAX_RETRIES = 3;
let after: string | null = null;
let totalCommentCount: number | null = null;
let pages = 0;

for (let pageIdx = 0; pageIdx < MAX_PAGES; pageIdx++) {
  let result: CommentsPageResult | null = null;
  let attempt = 0;
  for (;;) {  // retry loop — same shape as fetchLikersViaApi lines 297-345
    result = await this.page.evaluate( COMMENTS_PAGE_SNIPPET /* template STRING, not fn */ ).then(r => r as CommentsPageResult).catch(() => null);
    const ok = result && !result.error && (result.comments?.length ?? 0) > 0;
    if (ok) break;
    attempt++;
    if (!shouldRetryCommentsPage(result?.status ?? 0, result?.comments?.length ?? 0, attempt)) break;
    const backoff = 3000 * attempt;
    log.warn("IgPostUsers", `comments page ${pageIdx} failed (status ${result?.status ?? "network"}) — retry ${attempt}/${MAX_RETRIES} in ${backoff}ms`);
    await this.page.waitForTimeout(backoff);
  }
  if (!result || result.error || !result.comments?.length) {
    if (pageIdx === 0) {
      log.warn("IgPostUsers", "comments API first page failed — DOM/GraphQL capture results preserved");
      // DO NOT throw; extract() continues with whatever DOM + capture found (root cause 2 fix)
    }
    break;
  }
  if (!totalCommentCount && result.total) totalCommentCount = result.total;
  pages++;
  let added = 0;
  for (const c of result.comments) {
    if (!seen.has(c.username)) { seen.add(c.username); all.push({...}); added++; }
  }
  log.info("IgPostUsers", `comments page ${pageIdx}: +${added} → ${all.length} unique (hasNext=${result.hasNext})`);
  if (!result.hasNext || !result.endCursor) break;
  after = result.endCursor;
  if (this.ctx.maxResults > 0 && all.length >= this.ctx.maxResults) break;
  await this.page.waitForTimeout(1200);
}
log.info("IgPostUsers", `fetchCommentsViaApi: ${all.length} unique from ${pages} pages (post total: ${totalCommentCount ?? "?"})`);
```

`COMMENTS_PAGE_SNIPPET` = the existing in-page body as a TEMPLATE STRING (`(async () => { const {shortcode, after} = ${JSON.stringify({shortcode, after})}; ... })()`) — eliminates root cause 4. Inside it, use `pickCommentsConn` logic inline (the snippet is a string; keep it self-contained).

**Return shape change:** `{ users, totalCommentCount }`. Callers (extract step 4a) updated; also log `stop_reason: "source_exhausted"` only when `hasNext=false` or MAX_PAGES hit.

**Extract() 4a guard:** after `commenters` returns, if `commenters.length === 0` AND `collected.size === 0`, set progress `{ stop_reason: "comments_api_unavailable" }` — makes future failures diagnosable instead of silent rc=0.
