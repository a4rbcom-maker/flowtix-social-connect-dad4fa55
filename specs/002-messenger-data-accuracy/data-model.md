# Data Model: دقة بيانات جهات ماسنجر

**تاريخ**: 2026-07-29

---

## Entity: GraphQL Response (في الـ response handler)

يُمثل كل GraphQL response بين interceptsها الـ handler.

| الحقل | النوع | الوصف |
|-------|------|-------|
| `url` | `string` | رابط الـ API (graphql api) |
| `postData` | `string` | بيانات الـ POST request |
| `text` | `string` | متن الـ response |
| `docId` | `string` | الـ doc_id المستخرج من postData |
| `isMessenger` | `boolean` | هل الـ response ده من محادثات ماسنجر؟ |
| `gained` | `number` | عدد جهات الاتصال اللي استخرجت منه |

### Validation Rules
- `isMessenger = true` فقط إذا: postData يحتوي على thread/inbox/message_thread **أو** response text يحتوي على `"retrieve_biz_crm_contact"`, `"thread_key"`, `"last_message"`
- `isMessenger = false` قطعاً إذا: response text يحتوي على `"timeline_list_feed_units"` أو `"profile_for_intent_switching"`

## Entity: Extracted Contact

كائن يُمثل جهة اتصال مستخرجة من GraphQL response.

| الحقل | النوع | الوصف |
|-------|------|-------|
| `id` | `string` | Facebook user ID (بـ prefix msg_) |
| `name` | `string` | الاسم الظاهر |
| `avatarUrl` | `string` | رابط الصورة |
| `typename` | `string` | `__typename` من GraphQL (User, Page, إلخ) |
| `isPage` | `boolean` | هل هو صفحة مش مستخدم؟ |
| `isAutoGenerated` | `boolean` | هل الاسم مولّد أوتوماتيكياً؟ |
| `isDuplicate` | `boolean` | هل هو مكرر (نفس الـ ID أو الاسم)؟ |

### Validation Rules
- `isPage = true` إذا: `__typename` يساوي `"Page"`, `"Business"`, `"Organization"`, `"Store"`, `"Group"` **أو** الاسم يحتوي على كلمات تجارية/مؤسسية
- `isAutoGenerated = true` إذا: الاسم يطابق pattern `(Adventurous|Playful|Shiny)[A-Z][a-z]+\d+` **أو** الاسم هو `"WA Not Available"`
- يجب استبعاد أي contact فيه `isPage = true` أو `isAutoGenerated = true`

## Entity: Filter Rule

قاعدة تصفية تُطبق على الـ extracted contact قبل إضافته.

| الحقل | النوع | الوصف |
|-------|------|-------|
| `type` | `"typename" \| "name_pattern" \| "keyword" \| "self_reference"` | نوع القاعدة |
| `value` | `string \| RegExp` | القيمة أو النمط |
| `action` | `"exclude" \| "flag"` | إجراء: استبعاد أو تصنيف فقط |

### Ruleset
1. **Self-reference**: استبعاد إذا `id === excludeId` أو `id === pageId`
2. **Typename exclusion**: استبعاد إذا `__typename === Page|Business|Organization|Store|Group|Event|Application|Bot|App`
3. **MessagingActor exclusion**: استبعاد إذا `__isMessagingActor` يحتوي على page|bot|business|Page
4. **Auto-generated**: استبعاد إذا الاسم يطابق pattern auto-generated
5. **Keyword exclusion**: استبعاد إذا الاسم يحتوي على كلمات: News, Magazine, Store, Shop, School, University, Restaurant, Cafe, Airline, Entertainment, Recruiting, Airlines, Foundation, Institution
6. **Duplicate exclusion**: استبعاد إذا الـ id أو الـ name موجود بالفعل

## State Transitions

```
GraphQL Response (intercepted)
    │
    ├── isTimeline/ProfileSwitch? → │ Skip (لا استخراج)
    │
    ├── isMessenger? → deepParse(text)
    │    │
    │    walkJSON → Each candidate contact
    │         │
    │         ├── __typename = Page/Business/etc? → │ Exclude
    │         ├── __isMessagingActor = page/bot? → │ Exclude
    │         ├── Name matches auto-generated? → │ Exclude
    │         ├── Name matches keyword list? → │ Exclude
    │         ├── ID or Name already seen? → │ Skip (duplicate)
    │         └── PASSED ALL FILTERS → Add to contacts
    │
    └── Other → │ غير معروف - نترك للـ filter الحالي (لكن بدون استخراج)
```
